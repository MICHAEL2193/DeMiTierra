# DeMiTierra

Marketplace cloud-native orientado a la búsqueda y compra de productos alimentarios internacionales ofrecidos por comercios locales.

## Objetivo académico

Diseñar, desplegar y evaluar una arquitectura cloud-native reproducible en AWS mediante:

- Infraestructura como Código con Terraform
- Contenedores Docker
- CI/CD con GitHub Actions
- Observabilidad con Amazon CloudWatch
- Escalado automático
- Pruebas de carga reproducibles

## Componentes

- `backend`: API y lógica de negocio
- `frontend`: aplicación web
- `infrastructure`: infraestructura AWS
- `load-tests`: pruebas de carga
- `docs`: documentación del proyecto
